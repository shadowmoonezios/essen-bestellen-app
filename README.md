# Essen Bestellen App

## Übersicht
Diese Anwendung ermöglicht den Benutzern, einfach und bequem Essen in ihren Lieblingsrestaurants zu bestellen. Die Benutzer können durch verschiedene Menüs blättern, ihre Bestellungen aufgeben und Bewertungen für ihre Mahlzeiten abgeben.

## Features
- Benutzerregistrierung und -anmeldung
- Menübildschirm mit Such- und Filterfunktionen
- Warenkorb Funktionalität
- Bestellhistorie und Tracking
- Bewertungssystem für Gerichte

## Technologien
- Frontend: React.js
- Backend: Node.js mit Express
- Datenbank: MongoDB
- Authentifizierung: JWT

## Installation
1. Klone das Repository:
   ```bash
   git clone https://github.com/deinbenutzername/essen-bestellen-app.git
   ```
2. Installiere die Abhängigkeiten:
   ```bash
   cd essen-bestellen-app
   npm install
   ```
3. Starte die Anwendung:
   ```bash
   npm run start
   ```
